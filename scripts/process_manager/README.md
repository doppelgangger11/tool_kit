# Port Manager — скелет

Простой инструмент: сканирует все занятые (LISTEN) порты в системе
и позволяет завершать процессы, при необходимости запрашивая права
администратора через стандартный UAC-диалог Windows.

## Установка

```
pip install psutil
```

## Запуск

```
cd localhost_manager
python -m ui.main
```

## Структура

- `port_scanner.py` — `list_all_listening_ports()`: скан всех LISTEN-портов в системе через `psutil.net_connections()` (человекочитаемая замена `netstat -ano | findstr LISTENING`)
- `admin_utils.py` — работа с правами администратора:
  - `is_admin()` — запущено ли приложение уже с правами админа
  - `relaunch_as_admin()` — перезапустить всё приложение с elevation (UAC-диалог)
  - `kill_pid_plain(pid)` — обычное `taskkill /F /T /PID` без повышения прав
  - `kill_pid_elevated(pid)` — то же самое, но через `ShellExecuteW(..., "runas", ...)`, что вызывает системный UAC-диалог только для этой операции
- `ui/main.py` — Tkinter UI: таблица портов (порт/PID/процесс/протокол/командная строка), кнопка и двойной клик для завершения процесса, автообновление раз в 2 сек., баннер с предложением перезапуститься от администратора, если приложение сейчас запущено без прав

## Как работает завершение процесса

1. Сначала пробуем обычный `taskkill /F /T /PID <pid>` без прав администратора — для процессов текущего пользователя этого обычно достаточно.
2. Если ОС отвечает отказом в доступе — автоматически вызывается `ShellExecuteW` с verb `"runas"` для `taskkill`, что показывает **стандартный Windows UAC-диалог** именно на эту операцию, не требуя перезапуска всего приложения с правами администратора.

Отдельно есть баннер и кнопка "Перезапустить от администратора" — это на случай, если *сканирование* портов неполное (psutil без прав админа может не видеть часть соединений чужих процессов), а не только для завершения.

## Известные ограничения

- `ShellExecuteW` с `runas` — Windows-специфичный механизм; на других ОС `kill_pid_elevated` вернёт ошибку "поддерживается только на Windows" (там `kill_pid_plain` обычно достаточно — используется просто `psutil`/`kill -9`).
- `/T` в `taskkill` убивает всё дерево процессов — это осознанный выбор, чтобы не оставлять "осиротевшие" дочерние процессы (например, node, запущенный через npm).
- UAC-диалог, запущенный `ShellExecuteW`, — асинхронный и отдельный от Python-процесса; программа не блокируется в ожидании, а просто обновляет статус-бар и перечитывает список портов сразу после вызова (сам kill может ещё продолжаться на фоне, если пользователь не сразу нажал "Да" в диалоге).
